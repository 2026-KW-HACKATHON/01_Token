# 월계 들름길 (KW 해커톤 2026 · 1조 토큰좀주세요)

어디서 걸어도, 걸은 만큼 **서울 노원구 월계1동 동네 가게 쿠폰**으로 돌려받는 Expo 앱입니다.
걸음 → 보상 → 쿠폰 교환 → 가게 방문으로 이어지게 해 동네 상권 방문을 늘리는 것이 목표입니다.

> 시연용 앱입니다. 가게 4곳(이름·메뉴·가격·혜택·위치)은 모두 **가상**이며 실제로 사용할 수 없습니다.

## 실행 (Expo Go)

1. `.env.example`을 `.env`로 복사하고 카카오 REST 키, 네이버 검색 API ID·Secret을 넣습니다. (키는 커밋하지 않습니다)
2. `npm install`
3. `npx expo start --tunnel -c` 후 휴대폰 Expo Go로 QR을 찍습니다.
   - 터널이 실패하면(`failed to start tunnel`) 다시 실행하거나, 같은 와이파이·아이폰 핫스팟에서 `npx expo start --lan`.

시연 기기: iPhone + Expo Go. 안드로이드 APK는 만들지 않기로 했습니다(아래 "보류").

## 기능

| 화면 | 파일 | 내용 |
|---|---|---|
| 걷기 홈 | `src/app/(tabs)/index.tsx` | 오늘 걸음, 오늘 보상 5칸, 보상 받기, 내 보상 잔액, 매일 저녁 7시 알림 스위치, 시연 설정 |
| 혜택 지도 | `src/app/(tabs)/map.tsx` | 쿠폰 사용처 지도, 분류·예산 필터, 목록 맨 위 광고 자리 |

| 쿠폰함 | `src/app/(tabs)/coupons.tsx` | 티켓형 쿠폰, 매장 사용 확인(되돌릴 수 없음) |
| 사장님 화면 | `src/app/store-report.tsx` | 노출 → 조회 → 교환 → 사용 성과(7일·누적, 전환율). 걸음 데이터는 포함하지 않음 |

| 팝업 | `src/components/AdPopup.tsx`, `RewardReadyPopup.tsx` | 하루 한 번 광고 팝업("광고" 표시), 1,000보 단위를 넘으면 보상 알림 팝업 |

### 보상 규칙 (`src/lib/rewards.ts`)
- 1,000보마다 보상 1개, **하루 최대 5개**. 같은 걸음으로 다시 받을 수 없음.
- **걸음 수는 이월되지 않음**: 매일 0시에 0보부터, 5,000보를 넘긴 걸음은 보상 없음.
- **받은 보상(잔액)은 다음 날에도 남음**. 보상 10개 = 가게 쿠폰 1장(가게별 전용, 유효기간 있음).

### 걸음 측정 (`src/lib/steps.ts`, `src/store/WalkStore.tsx`)
- iPhone: Core Motion 기간 조회(오늘 0시~지금). 앱이 꺼져 있던 동안의 걸음도 포함.
- Android: 앱이 켜져 있는 동안만 센서로 측정(화면에 안내 문구 표시).
- 시연용 데이터: 990 / 1,000 / 2,800 / 5,600보, 잔액 9개. 화면에 "시연용 데이터 · 실제 측정 아님" 표시.

### 알림
- 매일 저녁 7시 로컬 알림(`src/lib/reminder.ts`, expo-notifications). 휴대폰에 예약하므로 앱이 꺼져 있어도 옴.
  앱이 꺼진 동안 걸음을 읽지 않으므로 알림 문구에 걸음·보상 개수는 없음. 알림을 누르면 걷기 홈으로 열리고, 받을 보상이 있으면 보상 알림 팝업이 뜸.
- 시연 설정: "10초 뒤 알림 테스트", "광고 팝업 다시 보기".

### 광고·데이터 원칙
- 광고 가게는 **날짜 순환**으로 정하고 걸음 수·잔액 등 걷기 데이터로 고르지 않음(애플 심사 지침 5.1.3: 건강·피트니스 데이터를 광고에 쓰지 않음).
- 가게에는 노출·조회·교환·사용 **횟수만** 보여 주고, 개인 걸음 기록은 공유하지 않음.

## 보류·알려진 한계
- **안드로이드 APK 보류**: 빌드 설정(`eas.json`, `docs/APK_BUILD.md`)은 있으나 빌드·실기기 확인은 하지 않음.
- **삼성헬스(헬스 커넥트) 연동 보류**: 안드로이드에서 앱이 꺼져 있던 동안의 걸음까지 읽는 코드를 만들었으나 미검증. 협업 저장소에 패치로 보관.
- 앱이 꺼진 동안 "1,000보를 넘는 순간" 알림은 Expo Go에서 불가(백그라운드 실행 필요).
- 로그인·서버가 없어 보상·쿠폰·가게 성과는 기기에만 저장되고, 사장님 화면은 이 기기 기록만 집계.
- 카카오·네이버 키가 앱 번들에 포함됨. 데모 이후 서버 프록시로 옮겨야 함.
- 이전 "동네 코스"(데이트 코스 추천) 화면은 코드만 남기고 탭에서 숨김(`course-find`, `courses`, `manage`).
